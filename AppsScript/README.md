# การติดตั้ง OpenRAH01 บน Google Apps Script

โฟลเดอร์นี้เป็นชุดไฟล์ Google Apps Script ที่พร้อมคัดลอกไปใช้กับ Google Sheets ซึ่งสร้างจาก `RAH01_Template.xlsx`

## วิธีติดตั้ง

ขั้นตอนใน Google Sheets

1. อัปโหลด `RAH01_Template.xlsx` ไปยัง Google Drive เปิดด้วย Google Sheets แล้วเลือก **ไฟล์ → บันทึกเป็น Google ชีต** เพื่อสร้างไฟล์ Google Sheets แบบ native สามารถตั้งชื่อไฟล์ใหม่เป็นชื่ออื่นได้
2. ไปที่ **ส่วนขยาย → Apps Script**

ขั้นตอนใน Apps Script

1. ตั้งชื่อโครงการ Apps Script เช่น `OpenRAH01`
2. ลบโค้ดเริ่มต้นใน `Code.gs` แล้ววางเนื้อหาจาก `Code.gs` ในโฟลเดอร์นี้
3. สร้างไฟล์ Script `.gs` และไฟล์ HTML `.html` ให้ครบ โดยตั้งชื่อให้ตรงกับไฟล์ในโฟลเดอร์ `AppsScript/`
   - [ ]  `Code.gs`
   - [ ]  `Config.gs`
   - [ ]  `Dictionaries.gs`
   - [ ]  `Storage.gs`
   - [ ]  `Submission.gs`
   - [ ]  `Index.html`
   - [ ]  `Styles.html`
   - [ ]  `Scripts.html`
4. เลือกเมนู **Project Setting** เปิดการแสดงไฟล์ Manifest `appsscript.json` และกลับมาที่เมนู **Editor**แล้วแทนที่เนื้อหาด้วยไฟล์จากโฟลเดอร์นี้
5. เลือกไฟล์ `Code.gs` และเลือกฟังก์ชัน dropdown เป็น `setupRah01Production` จากเมนูฟังก์ชัน แล้วกด **Run** หนึ่งครั้ง จากนั้นอนุญาตสิทธิ์ Google Sheets, Google Drive และข้อมูลตัวตนตามที่ระบบร้องขอ ขั้นตอนนี้ยังจำเป็นหนึ่งครั้งเพื่อติดตั้งโครงสร้างจัดเก็บ ขอสิทธิ์ระบบ และตรวจซ่อมสูตรกับกราฟให้เป็น Google Sheets แบบ native ไม่ใช่ขั้นตอนสร้างหรือทำให้แดชบอร์ดเริ่มแสดง ฟังก์ชันนี้เรียกซ้ำได้อย่างปลอดภัย

ขั้นตอนใน Google Sheets

1. เปิดแท็บ `Settings` ในไฟล์ Google Sheets ที่แปลงแล้ว และเปลี่ยนค่าในช่องสีเหลือง `H4` ข้าง `hospital_name` เป็นชื่อทางการของโรงพยาบาล
2. ใช้ไฟล์ Google Sheets นี้เป็นฐานข้อมูลต่อไป ไม่ต้องอัปโหลดไฟล์ Excel อีกชุดเพื่อเพิ่มหรือแทนแดชบอร์ด
3. ตรวจรายการแผนกในแท็บ `Settings` ผู้ดูแลเพิ่มแถวต่อท้ายได้โดยไม่ติดเพดาน 150 แผนก แต่ชื่อ รหัส ลำดับ และ `department_id` ต้องไม่ซ้ำกัน และต้องตั้ง `active` เป็น `TRUE` จึงจะแสดงในแบบฟอร์ม
4. ตรวจ Execution log หลังตั้งค่า และบันทึก Folder ID ของโฟลเดอร์เก็บรูปแนบส่วนตัวไว้

ขั้นตอนใน Apps Script

1. ก่อนรับข้อมูลจริง ให้เลือก `clearBundledSyntheticData` จาก function dropdown ใน `Code.gs` แล้วกด **Run** หนึ่งครั้งเพื่อล้างค่าตัวอย่างออก ระบบป้องกันจะไม่ยอมลบหากพบ assessment ID ที่ไม่ใช่ข้อมูลตัวอย่างของ template
2. เลือก **Deploy → New deployment → Web app** ตั้งให้ทำงานด้วยบัญชีผู้ดูแลโรงพยาบาลผู้ deploy และจำกัดสิทธิ์เฉพาะโดเมน Google Workspace ของโรงพยาบาล
3. เปิด URL ที่ลงท้ายด้วย `/exec` ตรวจว่าชื่อโรงพยาบาลแสดงใต้หัวข้อแบบประเมิน แล้วทดลองส่งข้อมูลที่ไม่ละเอียดอ่อนหนึ่งรายการ ตรวจข้อมูลในชีตปฏิบัติงานทั้งหกแท็บและโฟลเดอร์รูปแนบส่วนตัว

## ไฟล์ที่ต้องมี

- `Code.gs`
- `Config.gs`
- `Dictionaries.gs`
- `Storage.gs`
- `Submission.gs`
- `Index.html`
- `Styles.html`
- `Scripts.html`
- `appsscript.json`

## หลักการใช้งานและความปลอดภัย

- ห้ามเปิดโฟลเดอร์รูปแนบเป็นสาธารณะ
- ห้ามให้ผู้กรอกแบบฟอร์มทั่วไปมีสิทธิ์แก้ไข Google Sheets ฐานข้อมูล
- จำกัด Web app ให้ใช้ได้เฉพาะโดเมนของโรงพยาบาล
- เพิ่มผู้ดูแลเป็น Editor ของ Google Sheets แยกจากสิทธิ์ผู้กรอกแบบฟอร์ม
- ทดลองระบบด้วยข้อมูลทดสอบที่ไม่ละเอียดอ่อนก่อนใช้งานจริง
- ผู้ดูแลจัดการชื่อโรงพยาบาลและรายการแผนกผ่านแท็บ `Settings` ได้โดยไม่ต้องแก้โค้ด
- เมื่อแก้ไฟล์ Apps Script ต้องสร้าง deployment เวอร์ชันใหม่ มิฉะนั้น URL `/exec` จะยังใช้โค้ดเวอร์ชันเดิม
- โครงสร้างข้อมูลจากเบราว์เซอร์ยังคงเป็น `rah01-submission.v1` ส่วนข้อมูลไบต์ของรูปแนบส่งผ่าน argument แยกต่างหาก
- `submitRah01Assessment` รองรับการส่งซ้ำอย่างปลอดภัย เพราะ request UUID จากเบราว์เซอร์ถูกใช้เป็น assessment ID ที่เปลี่ยนไม่ได้
- ฝั่งเซิร์ฟเวอร์คำนวณคะแนนความเสี่ยงใหม่ทุกครั้ง และบันทึก snapshot ของชื่อแผนก วันที่ประเมิน และเลขที่รายงานไว้ในข้อมูลลูกทุกแถว
